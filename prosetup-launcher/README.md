# ProSetup Launcher

Лаунчер для быстрого запуска всего, что нужно перед игрой в **CS2** и на **FACEIT**.
Одна большая кнопка **«ЗАПУСТИТЬ МОЙ СЕТАП»** по очереди открывает:

| # | Действие | Как запускается | Как определяется статус |
|---|----------|-----------------|-------------------------|
| 1 | **Steam** | `steam.exe` (путь из реестра Valve / стандартные папки / вручную) | процесс `steam.exe` |
| 2 | **Настройки мыши Windows** | `control.exe main.cpl` (то же, что Win + R → `main.cpl`) | открыто окно «Свойства: Мышь» |
| 3 | **FACEIT Anti-Cheat** | `faceitclient.exe` (обычно `C:\Program Files\FACEIT AC\`); Windows покажет запрос UAC | процесс `faceitclient.exe` |
| 4 | **FACEIT в браузере** | https://www.faceit.com/ в Google Chrome (если не найден — в браузере по умолчанию; выбирается в настройках) | время последнего открытия |
| 5 | **Logitech G HUB** | `lghub.exe` (обычно `C:\Program Files\LGHUB\`) | процесс `lghub.exe` |

Приложение **только открывает программы и окна**. Оно не меняет DPI, чувствительность
мыши, системные параметры, параметры безопасности и ничего не пишет в реестр Windows.
Реестр только *читается*, чтобы найти пути установки.

## Возможности

- Тёмный интерфейс в киберспортивном стиле с оранжевыми акцентами, анимации наведения и нажатия.
- Карточка для каждой программы: переключатель «включить в сетап», статус, путь, кнопка запуска.
- Статусы реальные, по списку процессов Windows (обновление каждые 2 с):
  **Запущена / Запуск / Не запущена / Не найдена**.
- Уже запущенные программы повторно не запускаются (Steam не откроется вторым экземпляром,
  а если окно настроек мыши уже открыто, лаунчер просто переключится на него).
- Действия выполняются последовательно с паузой (по умолчанию 1,5 с, настраивается).
  Если одно действие завершилось ошибкой, остальные всё равно выполняются.
- Пути к программам определяются автоматически или задаются вручную: кнопка «Путь…» на карточке
  или окно «Настройки».
- Понятные уведомления об успехе и ошибках. Если окно свёрнуто, уведомление приходит из трея.
- Сворачивание в системный трей: кнопка «В трей», крестик окна (отключается в настройках)
  и меню трея «Запустить мой сетап».
- Настройки сохраняются в `%APPDATA%\ProSetupLauncher\settings.json`,
  журнал работы пишется в `%APPDATA%\ProSetupLauncher\launcher.log`.
- Запускается только один экземпляр: повторный запуск показывает уже открытое окно.
- Ключ `--minimized` запускает лаунчер сразу в трее.

«ЗАПУСТИТЬ МОЙ СЕТАП» и «Открыть всё» запускают одни и те же включённые действия. Разница одна:
после главной кнопки лаунчер может сам свернуться в трей, если в настройках включена опция
«Сворачивать в трей после запуска».

## Готовый EXE: скачать и запустить, Python не нужен

Скачайте `ProSetupLauncher.exe` со страницы релиза **ProSetup Launcher** в разделе Releases этого
репозитория и запустите его. EXE собирается автоматически на Windows-сервере GitHub Actions
(`.github/workflows/prosetup-launcher.yml`) и перед публикацией проходит самопроверку
`--selftest` на настоящей Windows.

**Портативный режим.** Собранный EXE хранит настройки в папке `ProSetupLauncher-data` рядом
с собой. Удобно для компьютерного клуба: положите EXE на флешку, и настройки не пропадут после
очистки ПК. Если в папку с EXE нельзя писать, используется `%APPDATA%\ProSetupLauncher`.

## Требования

- Windows 10 или Windows 11 (x64)
- Python **3.10+**, только для запуска из исходников или сборки. Готовому EXE Python не нужен.

## Запуск из исходников

```bat
cd prosetup-launcher
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

Можно проще: дважды щёлкните **`run.bat`**. При первом запуске он сам создаст окружение
и установит PySide6.

## Сборка самостоятельного EXE

Дважды щёлкните **`build.bat`** или выполните его в терминале. Скрипт:

1. создаёт виртуальное окружение `.venv`;
2. устанавливает PySide6 и PyInstaller;
3. генерирует иконку `assets\icon.ico`;
4. собирает один файл **`dist\ProSetupLauncher.exe`** (`--onefile --windowed`, без окна консоли).

Готовый `ProSetupLauncher.exe` можно скопировать в любую папку, закрепить на панели задач
или вынести ярлык на рабочий стол. Ставить Python для него не нужно.

> Однофайловые EXE от PyInstaller иногда ошибочно помечаются антивирусами. Если это случилось,
> добавьте файл в исключения или соберите в режиме папки: замените в `build.bat` `--onefile`
> на `--onedir`, тогда программа будет лежать в `dist\ProSetupLauncher\`.

## Если программа «Не найдена»

1. Нажмите **«Путь…»** на карточке и выберите исполняемый файл:
   - Steam: `steam.exe`
   - FACEIT AC: `faceitclient.exe` (папка `FACEIT AC`)
   - Logitech G HUB: `lghub.exe` (папка `LGHUB`)
2. Чтобы вернуть автоопределение, откройте **Настройки** и нажмите **«Авто»** напротив программы.

## Структура проекта

```
prosetup-launcher/
├── main.py                    точка входа
├── requirements.txt           зависимости (PySide6)
├── build.bat                  сборка EXE через PyInstaller
├── run.bat                    запуск из исходников
├── tools/make_icon.py         генерация assets/icon.ico
└── prosetup/
    ├── app.py                 QApplication, логирование, один экземпляр, обработка ошибок
    ├── actions.py             описание пяти действий и порядок запуска
    ├── config.py              загрузка/сохранение настроек (JSON, атомарная запись)
    ├── detect.py              автопоиск путей (чтение реестра и стандартных папок)
    ├── engine.py              статусы, проверка путей, запуск действий
    ├── worker.py              последовательный запуск в фоновом потоке
    ├── winapi.py              ctypes: список процессов, ShellExecuteEx, поиск окна мыши
    └── ui/
        ├── main_window.py     главное окно, трей, уведомления
        ├── settings_dialog.py окно настроек
        ├── widgets.py         переключатель, светящаяся кнопка, карточка, статус
        ├── toast.py           всплывающие уведомления
        ├── theme.py           цвета и стили (QSS)
        └── icon.py            иконка приложения, нарисованная кодом
```

## Технические детали

- Программы открываются через `ShellExecuteExW`, как из Проводника. Поэтому FACEIT AC, которому
  нужны права администратора, вызывает обычный запрос UAC. Если запрос отклонить, лаунчер покажет
  «запуск отменён пользователем», а не упадёт.
- Список процессов берётся через `CreateToolhelp32Snapshot` (WinAPI). Это быстро и не мигает
  окнами консоли.
- Запуск идёт в отдельном `QThread`, поэтому интерфейс не зависает, пока Windows показывает UAC.
- Если процесс не появился через 60 секунд после запуска, придёт предупреждение. Например, когда
  программа сразу закрылась или ушла в обновление.
