# FACEFUNNY

Юмористический визуальный **симулятор радара** в стиле Counter-Strike 2 для desktop.

> ⚠️ Это самостоятельная программа для развлечения. Она **не взаимодействует с процессом CS2**,
> не читает память игры, не использует игровые данные и не открывает сетевых соединений.
> Строка «подключения» — просто текст, который отображается в верхней панели.
> Всё движение игроков генерируется внутри приложения случайным образом.

## Возможности

- **Экран подключения**: крупный светящийся логотип, поле `Connect to server...`, кнопка **CONNECT**
  (или Enter), анимация «рукопожатия» и плавный переход на радар. Пустая строка — подсветка ошибки
  и «встряхивание» поля.
- **Радар Mirage**: стилизованная схема карты (A Site, B Site, Mid, CT Spawn, T Spawn, Palace,
  Apartments, Jungle, Market и т.д.), сетка и вращающийся луч радара.
- **10 игроков**: 5 синих CT у CT Spawn, 5 красных T у T Spawn. Наведение курсора показывает
  подсказку с командой и номером игрока.
- **F9** — запуск/пауза хаотичного движения всех игроков к A Site: у каждого свой маршрут
  (T — через A Ramp, Palace или Mid → Connector → Jungle; CT — через Ticket или Jungle),
  своя скорость, плавные повороты, случайные отклонения и остановки. Позиции интерполируются
  между тиками симуляции, маркеры не телепортируются и не выходят за пределы карты.
  Добравшись до A, игроки продолжают «топтаться» по точке.
- **F10** — вернуть всех на базы (движение останавливается).
- Кнопки **PAUSE/RESUME**, **RESET** (перезапуск симуляции с баз), **SOUND ON/OFF**, **DISCONNECT**.
- Верхняя панель: FACEFUNNY, MIRAGE, `SIMULATION: ACTIVE`, `PLAYERS 10/10`, статус движения, FPS.
- Ненавязчивые звуки интерфейса (синтезируются при запуске; если Qt Multimedia недоступен,
  приложение просто работает без звука).
- Поддержка изменения размера окна: карта масштабируется, сохраняя пропорции.

## Запуск

Нужен **Python 3.9+**.

### Windows

Дважды щёлкните `run_windows.bat`. При первом запуске он создаст виртуальное окружение `.venv`,
установит зависимости из `requirements.txt` и запустит приложение.

### Linux / macOS

```sh
./run.sh
```

### Вручную

```sh
python -m venv .venv
# Windows: .venv\Scripts\activate    Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

## Управление

| Клавиша / кнопка | Действие |
|---|---|
| Enter / CONNECT | Перейти к радару |
| F9 | Старт / пауза движения |
| F10 | Вернуть игроков на базы |
| PAUSE / RESUME | Пауза / продолжение |
| RESET | Перезапустить симуляцию с баз |
| SOUND | Включить / выключить звуки |
| DISCONNECT | Вернуться на экран подключения |

Горячие клавиши работают, когда окно FACEFUNNY активно (глобальный перехват клавиатуры
не используется намеренно — это потребовало бы сторонних зависимостей и системных прав).
Удержание F9 не переключает состояние многократно.

## Своё изображение карты

Положите локальный файл `assets/de_mirage_radar.png` — он будет нарисован под схемой.
Ничего не скачивается из интернета. Подробнее — в `assets/README.md`.

## Структура проекта

```
facefunny/
├── main.py              # точка входа, логирование, обработка ошибок
├── requirements.txt     # зависимости (PySide6)
├── run_windows.bat      # запуск в Windows
├── run.sh               # запуск в Linux/macOS
├── app/
│   ├── theme.py         # цвета, шрифты, stylesheet
│   ├── map_data.py      # геометрия стилизованной Mirage, маршруты, проходимость
│   ├── simulation.py    # логика движения (без Qt, фиксированный шаг + интерполяция)
│   ├── radar_view.py    # отрисовка карты, луча, маркеров, подсказок; цикл кадров
│   ├── connect_screen.py# первый экран
│   ├── radar_screen.py  # второй экран: панели, кнопки, статусы
│   ├── main_window.py   # окно, переходы между экранами, F9/F10
│   └── sound.py         # синтез и воспроизведение звуков интерфейса
├── assets/              # необязательное изображение карты
└── tests/               # тесты логики и headless-тест интерфейса
```

## Тесты

```sh
pip install -r requirements.txt
python -m unittest discover -s tests -v
```

UI-тест запускается без дисплея (`QT_QPA_PLATFORM=offscreen` выставляется автоматически).

Журнал ошибок пишется в `%TEMP%\facefunny.log` (Windows) или `/tmp/facefunny.log`.
